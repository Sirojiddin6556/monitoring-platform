# Спецификация системных требований (SRS) — Мониторинг серверов и веб-приложений

## 1. Введение
Настоящий документ описывает функциональные и технические требования к корпоративной системе мониторинга живучести, безопасности и нагрузки серверов (Windows/Linux) и веб-приложений.

## 2. Архитектура системы
Система состоит из трех основных модулей:
*   **Monitoring Agent (Go)**: Устанавливается на целевые серверы. Собирает метрики производительности, безопасности (VPN, SSH, пользователи), Docker-контейнеров, системных служб и парсит логи Nginx.
*   **Backend API (FastAPI)**: Принимает метрики от агентов по HTTP, осуществляет аутентификацию по токенам, хранит историю в PostgreSQL, кэширует состояние в Redis и рассылает алерты через Celery.
*   **Web UI (Next.js)**: Предоставляет панель управления (Dashboard) с real-time графиками, списком инцидентов, логами и управлением серверами.

## 3. Требования к сбору данных (Агент)
*   **Интервал опроса**: По умолчанию 15 секунд (настраиваемый).
*   **Метрики Нагрузки**: Загрузка CPU (общая и по ядрам), RAM, свободное место на дисках, I/O скорость дисков, скорость сети.
*   **Метрики Безопасности**: Количество активных пользователей, SSH-сессий, VPN-сессий (WireGuard/OpenVPN), список открытых портов (LISTEN), количество неудачных попыток входа за 24 часа.
*   **Контейнеры**: Статус (running/stopped), потребление CPU/RAM по каждому контейнеру.
*   **Веб-сервер**: RPS, распределение кодов ответов (2xx/3xx/4xx/5xx) из файла логов access.log.
