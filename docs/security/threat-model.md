# Модель угроз и безопасность системы мониторинга (Threat Model)

## 1. Идентификация активов
1.  **База данных PostgreSQL**: Содержит учетные данные администраторов, зашифрованные SSH/WinRM пароли серверов.
2.  **Токены авторизации агентов**: Позволяют отправлять метрики от имени серверов.
3.  **Системные логи**: Могут содержать конфиденциальные данные пользователей боевых серверов.

## 2. Анализ угроз по методологии STRIDE
*   **Spoofing (Спуфинг)**: Злоумышленник притворяется агентом и шлет ложные данные.
    - *Защита*: Аутентификация каждого запроса к `/api/metrics` по уникальному криптографическому токену `X-Ingest-Key`.
*   **Tampering (Целостность)**: Перехват и модификация метрик в процессе передачи.
    - *Защита*: Использование HTTPS TLS протокола для всех внешних запросов агента к бэкенду.
*   **Information Disclosure (Разглашение данных)**: Утечка зашифрованных паролей из БД.
    - *Защита*: Пароли SSH/WinRM шифруются симметричным ключом Fernet (`FIELD_ENCRYPTION_KEY`), который хранится исключительно в переменных окружения ОС и не коммитится в Git.
