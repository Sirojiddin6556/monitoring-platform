# План тестирования и контроля качества (QA Test Plan)

## 1. Стратегия тестирования
Проект покрывается тремя уровнями тестов:
1.  **Unit-тесты (PyTest / Go Test)**: Проверка парсеров логов, парсеров системного вывода (Get-Service, query user) и вспомогательных функций.
2.  **Интеграционные тесты API**: Проверка эндпоинтов авторизации, сбора метрик `/api/metrics` и получения деталей серверов.
3.  **End-to-End (E2E) тесты**: Симуляция работы агента, отправка тестовых метрик и проверка их моментального отображения на фронтенде по WebSocket.

## 2. Сценарий E2E тестирования сбора метрик безопасности
*   **Цель**: Убедиться, что новые метрики пользователей и VPN-сессий доходят до интерфейса.
*   **Шаги**:
    1. Запустить агент на тестовой Windows машине.
    2. Выполнить логин под вторым тестовым пользователем (RDP/локально).
    3. Поднять тестовое VPN-подключение.
    4. Открыть Web UI, перейти во вкладку "Безопасность" сервера `srv-1`.
    5. **Ожидаемый результат**: Число пользователей = `2`, число VPN-сессий = `1`.
