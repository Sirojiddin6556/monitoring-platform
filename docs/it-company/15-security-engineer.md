# 15. Security Engineer Report — Monitoring Platform Security Audit

## 1. Проведенный аудит и исправления
В бэкенде платформы мониторинга была обнаружена и устранена потенциальная уязвимость обхода авторизации (Authentication Bypass) по старым токенам:
- **Уязвимость**: Функция `get_current_user` декодировала JWT локально без сверки с базой данных. При блокировке пользователя администратором, его сессия оставалась активной до истечения JWT.
- **Исправление**: Метод `get_current_user` в [security.py](file:///C:/Users/Siroj/Desktop/Projects/backend/app/security.py) был изменен для выполнения асинхронного запроса к базе данных при каждом входящем запросе к API. Теперь проверяется статус `is_active` пользователя. При деактивации доступ отзывается немедленно (`401 Unauthorized`).
