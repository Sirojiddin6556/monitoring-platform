# 18. Penetration Tester Report — Monitoring Platform Penetration Test

## 1. Сфера тестирования (Scope)
Динамический аудит безопасности API бэкенда (`FastAPI`) и веб-клиента (`Next.js`) на локальном окружении перед деплоем в продакшн.

## 2. Найденные уязвимости и статус их закрытия

| Уязвимость | Описание | Критичность | Статус |
|------------|----------|-------------|--------|
| **Authentication Bypass via Stale Token** | Локальная проверка подписи JWT без сверки с базой данных позволяла заблокированным пользователям отправлять метрики и читать чужие логи. | **High** | **Закрыто (Fixed)** (добавлена принудительная валидация аккаунта в БД). |
| **Secrets Leaks in Repository** | Риск случайного коммита прод-файла конфигураций `.env.prod` в Git. | **Medium** | **Закрыто (Fixed)** (внедрен CI/CD Quality Gate). |
| **Excessive Dev Artifacts in Image** | Наличие компиляторов и dev-зависимостей Node/Python в финальных контейнерах, расширяющее поверхность атаки. | **Low** | **Закрыто (Fixed)** (внедрена Multi-stage сборка). |

---

## 3. Вердикт по результатам пентеста
После закрытия вышеописанных уязвимостей критических рисков безопасности и утечки данных в архитектуре платформы мониторинга не обнаружено. Продукт безопасен для вывода на рынок (SaaS).
