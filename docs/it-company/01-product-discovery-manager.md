# 01. Product Discovery Manager Report — Monitoring Platform Upgrade

## 1. Product Vision
* **Название продукта**: Infrastructure Monitoring Platform (Enterprise & SaaS Edition).
* **Суть**: Мульти-тенантная платформа мониторинга серверов (через Go-агент), веб-сайтов, Docker, Hyper-V/VirtualBox и Kubernetes с визуализацией в реальном времени.
* **Бизнес-цель**: Коммерческий продукт (SaaS) для продажи внешним клиентам. Ключевые требования: жесткая изоляция данных между организациями (мульти-тенантность), отказоустойчивость, высокая скорость загрузки интерфейса и минимальное потребление ресурсов инфраструктуры.

## 2. Product Requirements Document (PRD)

### Функциональные требования:
- [x] Ролевая модель (admin, user, viewer) с защитой API сессий в БД.
- [x] Сбор метрик в реальном времени (CPU, RAM, Disk, Network, Swap).
- [x] Мониторинг сторонних систем (Docker, K8s, VMs).
- [ ] Оптимизация структуры бэкенда: Распил `main.py` монолита (200 КБ) на независимые роутеры.
- [ ] Оптимизация фронтенда: Модульная загрузка стилей CSS для мгновенного рендеринга.

### Нефункциональные требования:
- Контейнеризация: Оптимизированные Docker-образы (Multi-stage builds) для минимизации размера и затрат на хостинг.
- Масштабируемость: Возможность обслуживать тысячи серверов без утечек памяти и зависаний.
- Безопасность: Предотвращение обхода авторизации (реализовано через БД-валидацию JWT) и защита секретов.

## 3. Риски и Ограничения
- **Риск**: Нарушение обратной совместимости API при переносе роутеров из `main.py`.
- **Контрмера**: Покрытие тестами API-эндпоинтов, валидация через `pytest` после каждого шага.

## 4. Roadmap проекта
1. **Этап 1 (Бизнес/Продукт)**: Оформление PRD и требований. (Выполнено)
2. **Этап 2 (Архитектура)**: Solution & Database Architect планируют декомпозицию `main.py` и рефакторинг схемы стилей.
3. **Этап 3 (Разработка)**: Выполнение рефакторинга бэкенда и оптимизация фронтенд стилей.
4. **Этап 4 (DevOps)**: Перевод Docker-сборок на Multi-stage.
5. **Этап 5 (QA & Security)**: Полное тестирование и аудит безопасности.
